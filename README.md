# 熊猫归山｜雅安大熊猫生态互动叙事游戏

这是一个数字媒体技术毕业设计网页游戏原型。作品以雅安大熊猫生态保护为主题，结合雨城、森林、茶山、栖息地等地方文化与生态空间，完成“地方文化 IP + 网页互动游戏 + 自然教育”的综合表达。

## 作品定位

- 作品名称：熊猫归山
- 类型：网页互动叙事游戏 / 生态教育 H5 原型
- 技术路线：HTML + CSS + JavaScript + Phaser 3
- 展示方式：浏览器直接打开，后续可部署 GitHub Pages
- 适用场景：毕业设计答辩、文旅互动展示、亲子生态教育、景区 H5 活动

## 玩法说明

玩家扮演“小雨团”，在巡护员引导下完成四个章节任务：

1. 第一章：雨城出发
2. 第二章：森林巡护
3. 第三章：茶山同行
4. 第四章：熊猫归山

操作方式：

- ← → / A D：左右移动
- ↑ / W / 空格：跳跃
- 收集绿色生态物：增加生态值
- 避开红色干扰区：避免生态值下降

## GitHub Pages 部署

仓库已包含 `.github/workflows/deploy-pages.yml` 自动部署工作流。若 Pages 未自动上线，请进入：

Settings → Pages → Build and deployment → Source 选择 GitHub Actions

如果仓库为 private，免费账号可能无法直接发布 GitHub Pages，建议将仓库设置为 public。

## 毕业设计创新点

1. 以雅安大熊猫为核心文化符号，具备国内外传播识别度。
2. 将生态保护知识转化为可玩的关卡任务，避免纯图文科普的单调。
3. 采用网页游戏形式，便于部署、传播和答辩演示。
4. 串联雨城、森林、茶山、栖息地，形成地方文旅叙事。
5. 可扩展为景区亲子研学小游戏、公众号 H5 活动、生态教育互动屏。
