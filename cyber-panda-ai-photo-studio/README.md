## 作品定位

- 作品名称：赛博竹林 · AI熊猫合影工坊
- 类型：生成式互动网页 / 文旅打卡 H5 原型
- 主题：成都熊猫 IP、赛博竹林、AI 合影、粒子交互
- 技术路线：HTML + CSS + JavaScript + Canvas 粒子动画
- 展示方式：浏览器直接打开 `index.html`

## 当前版本已包含

- 单文件静态网页
- 熊猫主题主视觉标题
- Canvas 粒子动画
- 鼠标靠近牵引效果
- 点击 / 触控互动反馈
- 手机端响应式适配

## 后续可扩展

1. 上传游客照片。

3. 接入 Runway / 视频模型生成 5–8 秒动态短片。
4. 增加 Suno 生成的治愈背景音乐。
5. 做成成都文旅展厅大屏、景区 H5 或毕业设计答辩互动页面。
